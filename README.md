## 功能

| 模块 | 亮点 |
| --- | --- |
| 首页信息流 | **接入官方推荐系统**：推荐 / 真人剧 / 漫剧 / 系列剧 / 热播榜五路内容；进中栏即播 |
| 推荐系统 | 曝光与点击实时回传，推荐结果跟着你的观看与点击走；换一批、滚动续拉、待上线剧上线后置顶 |
| 剧场 / 排行 / 找剧 | 分类信息流、一级 / 二级榜单（含演员榜）、筛选项与榜单规则全部由服务端下发 |
| 搜索 | 关键词搜索，多路召回；结果按系列归并，搜一部剧直接列出它的全部季；历史与清空 |
| 详情 / 系列剧 | 同一系列各季自动归组、按季号排序、番外排在正片之后、未上线季可就地预约 |
| 播放 | 多档清晰度切换（切档保持进度）、相邻集预解码、进度记录与续播、播完自动连播 |
| 弹幕 | 弹幕池由本集评论生成 + 自己发送的弹幕；开关 / 字号 / 不透明度 / 显示区域 / 速度 / 屏蔽词 |
| 评论 | 真实昵称与头像、分页加载、发表评论与回复、点赞、草稿按剧保存（均在本机） |
| 我的 | 收藏 / 历史 / 预约（已上线 / 待上线两栏），全部保存在本机，卸载不删 |
| 窗口 | 小窗态、铺满窗口、全屏、置顶、自定义快捷键、右键操作菜单 |
| 数据与边界 | 内容与推荐全部实时取自官方服务端，**不使用假数据兜底**；不提供账号登录 |

**关于推荐**：首页流是官方推荐系统按行为算出来的结果，不是一批固定选品。客户端**不在本地改写或过滤**
推荐内容，而是把「哪些已经给你看过、哪些你点过」随请求回传给服务端 —— 所以流里的东西会跟着你的
观看与点击变，看过的剧也不会反复推。拿不到就是空态，不会拿本地编造的内容顶上。

完整清单与各项支持程度见 [docs/features.md](docs/features.md)。
