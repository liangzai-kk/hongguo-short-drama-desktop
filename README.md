## 更新记录

### 0.1.3

- 修复首次安装后偶发「整页加载不出来、点重试也没用」：本机后台组件按新设备信息重建之后会卡住（进程还在、但不再应答），此后所有内容都取不到，只能重启应用。现在换成启动一个干净的后台组件；「活着但不应答」也会被当场识别并自动重启。
- 修复新装机首次启动时设备信息不完整（机型 / 分辨率 / 屏幕密度按兜底值上报），推荐结果因此可能不稳定。
- 优化启动速度：第一次安装的首屏从约 7 秒降到约 4 秒（设备注册改到后台进行，不再挡住首屏加载）。
- 修复详情页「选集」只显示 24 集：现在给出「展开全部 / 收起」，可看完整分集。
- 界面加载失败现在会自己重试，不再需要反复手点「重试」；如果本机组件是被安全软件拦掉的，界面会直接说明。
- 修复弹幕来源问题：改为真实观众的弹幕，不再是本地合成的假弹幕。
- 修复弹幕显示问题：弹幕跟着播放进度分段加载，起播、拖动进度条都能对上位置，不再堆积或空白。
- 优化弹幕设置：支持发送、清屏，字号 / 不透明度 / 显示区域 / 速度 / 屏蔽词均可调。
- 新增小窗模式：看剧时把窗口缩成只装画面的小窗，置顶悬在其他窗口上；可拖动、可最小化，一键还原。
- 新增应用内更新：设置页直接检查新版本并下载安装，不用再回网页手动下载。
- 优化找剧页：筛选维度补齐到与手机 App 一致（体裁、情节、主题、背景、角色、集数、受众、排序），支持多条件组合筛选，换条件立刻换一批。
- 优化搜索页：新增「猜你想搜」与热搜榜，点词条直接出结果。
- 优化评论：点头像或昵称可进入该用户主页。

完整更新记录见 [CHANGELOG.md](CHANGELOG.md)。
