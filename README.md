## 功能

| 模块 | 亮点 |
| --- | --- |
| 首页信息流 | **接入官方推荐系统**：推荐 / 真人剧 / 漫剧 / 系列剧 / 热播榜五路内容；进中栏即播 |
| 推荐系统 | 曝光与点击实时回传，推荐结果跟着你的观看与点击走；换一批、滚动续拉、待上线剧上线后置顶 |
| 剧场 / 排行 / 找剧 | 分类信息流、一级 / 二级榜单（含演员榜）、筛选项与榜单规则全部由服务端下发 |
| 搜索 | 关键词搜索，多路召回；搜索框联想下拉（空框给最近搜索，打字给联想）；猜你想搜与热搜榜；结果按系列归并，搜一部剧直接列出它的全部季；历史与清空 |
| 详情 / 系列剧 | 同一系列各季自动归组、按季号排序、番外排在正片之后、未上线季可就地预约 |
| 播放 | 多档清晰度切换（切档保持进度）、相邻集预解码、进度记录与续播、播完自动连播 |
| 弹幕 | 真实观众弹幕，跟随播放进度实时出现；可发送、清屏；开关 / 字号 / 不透明度 / 显示区域 / 速度 / 屏蔽词 |
| 评论 | 真实昵称与头像、分页加载、发表评论与回复、点赞、草稿按剧保存（均在本机）；点头像 / 昵称进用户主页 |
| 我的 | 收藏 / 历史 / 预约（已上线 / 待上线两栏），历史可按剧名检索，全部保存在本机，卸载不删 |
| 窗口 | 小窗态（画面窄窗、可置顶拖动）、铺满窗口、全屏、置顶、自定义快捷键、右键操作菜单 |
| 更新 | 设置页检查新版本，直接下载安装 |

完整清单与各项支持程度见 [docs/features.md](docs/features.md)。

## 更新记录

### 0.1.5

- 新增搜索框联想：点搜索框先给最近搜过的词，边输入边给联想，剧条目点一下直接看；搜索历史保存在本机（上限 20 条，可清空）。
- 观看历史页支持按剧名检索。
- 列表为空时给出空态提示（观看记录 / 收藏 / 预约 / 评论 / 搜索无结果），不再只剩一个加载点。
- 我的页的历史与收藏改为全量列表（原先只列最近 12 条）。
- 修复点选集后高亮先跳、画面还在放上一集：现在点击当场停住旧画面并转圈，命中预解码就直接接上。
- 修复首页「下一部要转圈几十秒」：上一版改动把预解码的触发条件挡掉了，现已恢复。
- 修复「明明看过，从历史或收藏进去却从头开始」：续播位置取本机记录与本次会话中更靠后的一份。
- 修复点进度条后被续播位置顶回开头；看完结尾的剧集不再自动翻到下一集。
- 修复切换清晰度失败后黑屏：失败自动接回上一档。
- 起播更快：签名组件启动时先热身一次；后台预取给「正要看的这一集」让路，不再抢带宽。
- 鼠标停在卡片上即提前准备这一集（历史 / 收藏 / 搜索 / 找剧 / 剧场 / 相关推荐均生效）。
- 小窗与「铺满窗口」共用一条顶部浮层；小窗高度被记住，拖动不会把窗口甩出屏幕。
- 详情与「系列剧 / 相关推荐」分开加载，切季与进播放页不用等整套数据。
- 观看记录上限提升到 2000 条；同一部剧不再出现重复记录。
- 修复评论可能显示上一部剧的集数。

完整更新记录见 [CHANGELOG.md](CHANGELOG.md)。
