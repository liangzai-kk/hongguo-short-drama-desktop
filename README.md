## 功能

| 模块 | 亮点 |
| --- | --- |
| 首页信息流 | **接入官方推荐系统**：推荐 / 真人剧 / 漫剧 / 系列剧 / 热播榜五路内容；进中栏即播 |
| 推荐系统 | 曝光与点击实时回传，推荐结果跟着你的观看与点击走；换一批、滚动续拉、待上线剧上线后置顶 |
| 剧场 / 排行 / 找剧 | 分类信息流、一级 / 二级榜单（含演员榜）、筛选项与榜单规则全部由服务端下发 |
| 搜索 | 关键词搜索，多路召回；搜索框联想下拉（空框给最近搜索，打字给联想）；猜你想搜与热搜榜；结果按系列归并，搜一部剧直接列出它的全部季；历史与清空 |
| 详情 / 系列剧 | 同一系列各季自动归组、按季号排序、番外排在正片之后、未上线季可就地预约 |

| 弹幕 | 真实观众弹幕，跟随播放进度实时出现；可发送、清屏；开关 / 字号 / 不透明度 / 显示区域 / 速度 / 屏蔽词 |
| 评论 | 真实昵称与头像、分页加载、发表评论与回复、点赞、草稿按剧保存（均在本机）；点头像 / 昵称进用户主页 |
| 我的 | 收藏 / 历史 / 预约（已上线 / 待上线两栏），历史可按剧名检索，全部保存在本机，卸载不删 |
| 窗口 | 小窗态（画面窄窗、可置顶拖动）、铺满窗口、全屏、置顶、自定义快捷键、右键操作菜单 |
| 更新 | 设置页检查新版本，直接下载安装 |

## 更新记录

### 0.1.6

- 新增更新提示弹窗：发现有新版本时弹一次窗口，里面写清「新版本是几号、你现在是几号、这次改了什么」，可以「立即更新」或「稍后」；下载过程带真实进度，下好直接安装。顶栏保留入口，随时能再打开。
- 修复「点下载更新没反应、变成重试」：更新请求带着界面内部的对象交给后台，跨进程传不过去，请求在发出前就被丢掉（连日志都没留下）。现在请求能正常发出，下载随即开始。
- 修复「安装包一秒就下完、装的时候才发现不对」：某条加速线路把一页错误提示当成安装包回了过来，现在下载会核对大小，只认真正的安装包。
- 界面文字可以选中复制：更新内容、评论正文、剧情简介这些都能选中并复制；按钮、导航这类骨架仍不参与选中，拖窗口时不会把文案刷蓝。
- 清晰度选过一次就记住：在播放页调到 1080P，下一集、下一部都按这个档位播，不用每集重选一遍；某一集没有这一档时，用这一集可用的最高档。
- 没选过清晰度时默认用最高档（原先默认 720P）。
- 切换清晰度之后，下一集按新档位重新准备；原先可能拿旧档的画面接上，看着像没生效。
