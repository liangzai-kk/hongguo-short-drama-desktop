## 更新记录

### 0.1.11

- 新增「金币」：余额与任务列表、7 日签到与奖励领取、看剧攒金币。
- 新增「点赞」：「我的 → 点赞」按集展示、可取消；播放页与原生播放窗点赞；评论点赞。
- 评论模块重做：最热 / 最新排序、回复详情页、长文折叠、按集草稿、头像与空态。
- 新增顶栏账号区、播放窗口设置（独立窗口 / 应用内）、首页信息流角标与推荐标签、系列剧未上线季预约入口。
- 原生播放窗新增右缘操作栏（点赞 / 评论 / 收藏）。
- 账号数据改为本地缓存 + 后台更新，历史、收藏、预约进入即显示；观看历史进入播放、切集即记录。
- 原生播放窗音画链路与窗口交互优化：音画读取与音频时钟、标题栏拖动 / 最大化 / 全屏 / 铺满态窗口键、控制条半透明浮层、浮层随窗口移动。
- 画质增强切档更顺滑，补帧闪烁与卡顿减少；弹幕字重与对比度提升。
- 修复播放中没声音 / 断续、看一半跳集、拖动进度条回退重解、补帧没声音 / 卡顿 / 闪烁、倍速杂音、暂停后音画不同步、切超分档崩溃、全屏退不出、控制条遮挡字幕等问题。

### 0.1.10

- 播放画面改用 Qt 原生播放窗口。
- 实时超分接入渲染性能优化；NVIDIA 超分 / FSR / DLSS-SR 三种后端自动选。

### 0.1.9

- 修复全屏时开关画质增强不生效。
- 修复全屏下 Esc 退不出去。
- 修复点过控制条按钮后空格等快捷键失效。
- 实时超分帧率稳定性优化：新增输入分辨率档位、取帧并行、自动降级改为先降质量再降档位。

### 0.1.8

- 新增实时超分（画质增强，默认关闭，设置页手动开）：播放中逐帧走显卡官方算法，1080P 源直上 2K / 4K，四档质量 + 锐度可调；不写临时文件、不额外等待，算力跟不上自动降到低一档。
- 增强面板附带锐度调节；补帧与 HDR 转换默认关闭。
- 显卡不支持或缺少运行组件时增强不生效，画面自动回落原视频，播放本身不受影响。
- 修复开启增强后画面闪烁、掉帧：取帧改到独立线程里做，主界面不再被拖慢。
- 修复窗口缩放、右栏收起、切换小窗后增强画面错位或出现重影。
- 设置页滑杆拖动过程中不再反复触发保存；暂停时调节增强参数立刻生效。

### 0.1.7

- 新增本地数据导出 / 导入：历史与分集进度、收藏、预约、自己发的评论与弹幕、搜索历史、评论草稿、播放偏好，一次搬到新机器；导出是一个压缩备份文件（原先的明文备份动辄几 MB），旧版本导出的备份照样能导进来。
- 导出完成会告诉你导出了哪个文件、多大，并给一个「在文件夹中显示」，一步跳到文件所在位置。
- 导入分两步走：先选文件，再确认（确认框里带上刚选中的文件名）；导入完成汇总每个分区实际搬进来多少条。
- 清除本地数据从导出 / 导入那一排里挪出来，独占一行并用分隔线隔开，点它先确认 —— 原先手一滑就点到。
- 设置页「本地数据」分区给出实时条数（历史 / 收藏 / 预约）；正在进行的动作只让自己转圈，另一个照常可点。
- 预约页拆成「已预约 / 即将上线 / 已上线」三栏，进来默认停在「已预约」；「即将上线」不再和已经能看的剧混在一栏。
- 待上线的剧在卡片上就能预约 / 取消预约（原先得进详情，而未上线的剧详情打不开）；从详情或播放页返回预约页会先出上次那份清单，不再整页重刷。
- 详情页的播放按钮拆成「继续播放」和「播放（从头看）」：看过的剧接着上次看，想重看从头来点旁边那一颗。
- 进度条可以预览了：鼠标移到进度条上就能看到那一刻的画面，拖动时跟着走，想找哪一段不用一点点试。
- 修复两处历史丢失：播放中强制退出导致整部剧的记录消失；旧版本里看过的剧，升级后历史里一条都没有。
- 修复个别操作点了没反应：界面数据出后台通道时没能序列化过去，请求在发出前就丢了。
- 搜索历史的词条可以单条删除了（整组「清空」照旧）。
