# 功能一览

> 本页列出程序有什么功能，以及**当前版本的实际支持程度**。
>
> 标记：**已支持** ／ **部分支持**（注明缺口）／ **暂未支持**

---

## 一、内容发现

### 1.1 首页信息流

| 功能 | 程度 |
| --- | --- |
| 首页信息流，五路内容：推荐 / 真人剧 / 漫剧 / 系列剧 / 热播榜 | 已支持 |
| 进入中栏即播：首页可直接观看，不必先进详情页 | 已支持 |
| 推荐内容跟随你的观看与点击行为变化 | 已支持 |
| 三路内容：推荐 / 真人剧 / 漫剧 | 已支持 |
| 换一批（左栏再点「首页」） | 已支持 |
| 滚动到底自动续拉 | 已支持 |
| 待上线预约的剧集上线后置顶到流顶部（最多 3 条） | 已支持 |
| 下拉刷新手势 | 暂未支持（刷新用左栏点击） |

**推荐怎么来的**：推荐结果由内容服务端实时下发，客户端**不在本地改写推荐结果**，
也**不按本地观看记录过滤**内容。你的曝光与点击行为会随请求一并上报给服务端，
用于生成后续推荐 —— 这也是为什么流的内容会跟着你的操作变。

### 1.2 搜索

| 功能 | 程度 |
| --- | --- |
| 输入关键词搜索 | 已支持 |
| 搜索历史（本地保存，上限 20 条，可清空） | 已支持 |
| 结果滚动续拉 | 已支持 |
| 结果按系列归并：搜一部剧直接列出它的全部季，不混入无关推荐 | 已支持 |
| 搜索联想下拉 | 暂未支持 |
| 热搜榜 / 热词入口 | 暂未支持 |

### 1.3 剧场

| 功能 | 程度 |
| --- | --- |
| 分类信息流（双列网格） | 已支持 |
| 「继续播放」卡片 | 已支持 |
| 系列剧 / 排行快捷入口 | 已支持 |

### 1.4 排行榜

| 功能 | 程度 |
| --- | --- |
| 一级 / 二级榜单切换，榜名与榜单规则由服务端下发 | 已支持 |
| 滚动续拉 | 已支持 |
| 演员榜条目的独立落地页 | 暂未支持（不提供假入口） |

### 1.5 找剧

| 功能 | 程度 |
| --- | --- |
| 分类筛选，筛选项由服务端下发 | 已支持 |
| 列表分页 | 已支持 |
| 排序入口 | 暂未支持（排序数据已取到，界面未接线） |

> 筛选为**单选**：一次只能筛一个维度，换维度会覆盖上一个 —— 这是内容站点的能力上限，
> 客户端不发明多选语义。

## 二、剧集详情与系列剧

| 功能 | 程度 |
| --- | --- |
| 详情页：简介、标签、演员、总集数与可看集数 | 已支持 |
| 互动数据：每集点赞、追剧数、评论数 | 已支持 |
| 中栏选集预览 | 已支持 |
| 系列剧归组：同一系列的各季识别到一起 | 已支持 |
| 各季按季号排序，番外排在正片之后 | 已支持 |
| 未上线季显示预约入口 | 已支持 |

系列剧面板的交互分工：

- **整行点击** = 直接播这一季；
- **封面左上角的季角标** = 进这一季的详情页；
- **未上线的季** = 整行进详情页（那里才有大号预约按钮）。

## 三、播放

| 功能 | 程度 |
| --- | --- |
| 播放（画面是窗口内的一张普通视频层，与界面同一套层级） | 已支持 |
| 清晰度切换，档位由服务端下发，界面列出全部档 | 已支持 |
| 切档保持当前进度 | 已支持 |
| 切换剧集 / 播完自动连播 | 已支持 |
| 播放进度记录与续播（每 5 秒记录一次，退出前补记） | 已支持 |
| 分集进度（回到早前看过的集，可接着看） | 已支持 |
| 相邻集预解码，切集几乎零等待 | 已支持 |
| 小窗态（同一扇窗口的收起态，可拖边调尺寸，高度被记住） | 已支持 |
| 铺满窗口 / 全屏 | 已支持 |
| 窗口置顶（任何页面、任何形态都能开） | 已支持 |
| 快捷键（可自定义，按键冲突自动对调） | 已支持 |
| 右键操作菜单（播放 / 暂停、上下一集、弹幕、清屏、静音、评论、赞、收藏、全屏、详情） | 已支持 |
| 全局默认清晰度记忆 | 暂未支持（清晰度按当前播放的这一集生效） |

**同一时刻只有一路声音**。切集时上一集的解码产物立即释放，画面不会被上一部剧顶替。

## 八、总体说明

- 本程序**不提供账号登录**，个人数据（历史 / 收藏 / 预约 / 评论草稿 / 弹幕）全部保存在本机。
- 所有内容、推荐结果、榜单与筛选项均来自内容服务端实时下发，**不使用假数据兜底**：
  拿不到就是空态或失败态，不用本地编造的内容顶上。
- 界面不显示任何技术诊断信息；失败时只提供动作（重试），不写原因小作文。

固定骨架：顶栏 56px + 左栏 72px + 中栏自适应 + 右栏 360px（可收起）。
页间跳转只在中栏内发生，不整窗跳转、不新开窗口；面板弹出**不做遮罩**，
画面就在旁边，不压暗、不暂停。窗口宽 < 1200 时右栏自动收起。

小窗态不是第二个窗口 —— 是同一扇窗口收成一扇只装画面的窄窗，
画面、播放实例、进度全部原地不动，还原后接着播。

其余界面（剧场 / 排行榜 / 找剧 / 搜索 / 设置）见仓库首页。
