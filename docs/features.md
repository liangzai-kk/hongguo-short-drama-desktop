# 功能一览

> 本页列出程序有什么功能，以及**当前版本的实际支持程度**。
>
> 标记：**已支持** ／ **部分支持**（注明缺口）／ **暂未支持**

---

## 一、内容发现

### 1.1 首页信息流

| 功能 | 程度 |
| --- | --- |
| 首页信息流，五路内容：推荐 / 真人剧 / 漫剧 / 系列剧 / 热播榜 | 已支持 |
| 进入中栏即播：首页可直接观看，不必先进详情页 | 已支持 |
| 推荐内容跟随你的观看与点击行为变化 | 已支持 |
| 换一批（左栏再点「首页」） | 已支持 |
| 滚动到底自动续拉 | 已支持 |
| 待上线预约的剧集上线后置顶到流顶部（最多 3 条） | 已支持 |
| 下拉刷新手势 | 暂未支持（刷新用左栏点击） |

### 1.2 搜索

| 功能 | 程度 |
| --- | --- |
| 输入关键词搜索 | 已支持 |
| 搜索历史（本地保存，上限 20 条，可清空） | 已支持 |
| 搜索框联想下拉（空框给最近搜索，打字给联想；剧条目可直接开播） | 已支持 |
| 结果滚动续拉 | 已支持 |
| 结果按系列归并：搜一部剧直接列出它的全部季，不混入无关推荐 | 已支持 |
| 发现态：「猜你想搜」词条与热搜榜，点词条直接出结果 | 已支持 |

### 1.3 剧场

| 功能 | 程度 |
| --- | --- |
| 分类信息流（双列网格） | 已支持 |
| 「继续播放」卡片 | 已支持 |
| 系列剧 / 排行快捷入口 | 已支持 |

### 1.4 排行榜

| 功能 | 程度 |
| --- | --- |
| 一级 / 二级榜单切换，榜名与榜单规则由服务端下发 | 已支持 |
| 滚动续拉 | 已支持 |
| 演员榜条目（圆头像 / 演员名 / 代表作 / 标签）在榜内显示 | 已支持 |
| 演员榜条目的独立落地页 | 暂未支持（落地页属另一套体系，不提供点了没反应的入口） |

### 1.5 找剧

| 功能 | 程度 |
| --- | --- |
| 分类筛选，筛选项由服务端下发（体裁、情节、主题、背景、角色、集数、受众、排序） | 已支持 |
| 多个维度可组合筛选，换条件立刻换一批 | 已支持 |
| 列表分页 | 已支持 |
| 维度行可收起 / 展开 | 已支持 |

---

## 二、剧集详情与系列剧

| 功能 | 程度 |
| --- | --- |
| 详情页：简介、标签、演员、总集数与可看集数 | 已支持 |
| 互动数据：每集点赞、追剧数、评论数 | 已支持 |
| 中栏选集预览（超过 24 集给「展开全部 / 收起」出口） | 已支持 |
| 看过的主按钮为「继续播放」，另给「播放（从头看）」 | 已支持 |
| 系列剧归组：同一系列的各季识别到一起 | 已支持 |
| 各季按季号排序，番外排在正片之后 | 已支持 |
| 未上线季显示预约入口 | 已支持 |
| 评分 / 热度 | 服务端不下发时**留空，不编造** |

系列剧面板的交互分工：

- **整行点击** = 直接播这一季；
- **封面左上角的季角标** = 进这一季的详情页；
- **未上线的季** = 整行进详情页（那里才有大号预约按钮）。

## 三、播放

| 功能 | 程度 |
| --- | --- |
| 播放（画面是窗口内的一张普通视频层，与界面同一套层级） | 已支持 |
| 清晰度切换，档位由服务端下发，界面列出全部档 | 已支持 |
| 清晰度记忆（选过的档位跟着走，不用每集重选） | 已支持（按分辨率短边记住；这一集没有那一档时用可用的最高档） |
| 未选过清晰度时的默认档 | 已支持（取可用的最高档） |
| 切档保持当前进度 | 已支持 |
| 切换剧集 / 播完自动连播 | 已支持 |
| 播放进度记录与续播（每 5 秒记录一次，退出前补记） | 已支持 |
| 分集进度（回到早前看过的集，可接着看） | 已支持 |
| 进度条悬停 / 拖动时预览该时刻的画面 | 已支持 |
| 相邻集预解码，切集几乎零等待 | 已支持 |
| 小窗态（同一扇窗口的收起态，可拖边调尺寸，高度被记住） | 已支持 |
| 铺满窗口 / 全屏 | 已支持 |
| 窗口置顶（任何页面、任何形态都能开） | 已支持 |
| 快捷键（可自定义，按键冲突自动对调） | 已支持 |
| 右键操作菜单（播放 / 暂停、上下一集、弹幕、清屏、静音、评论、赞、收藏、全屏、详情） | 已支持 |
| 画质增强：实时超分（默认关闭，设置页开启；不写临时文件） | 已支持（需 NVIDIA 显卡；算力跟不上自动降档） |
| 画质增强：锐度调节 | 已支持 |
| 画质增强：补帧 / HDR 转换（默认关闭） | 已支持（补帧需厂商运行组件；HDR 转换效果打磨中） |

**同一时刻只有一路声音**。切集时上一集的解码产物立即释放，画面不会被上一部剧顶替。

## 四、弹幕

| 功能 | 程度 |
| --- | --- |
| 弹幕显示（覆盖在画面上，随画面尺寸变化） | 已支持 |
| 弹幕来源：真实观众的弹幕，跟随播放进度分段加载 | 已支持 |
| 发送弹幕（本地保存，每集上限 500 条） | 已支持 |
| 弹幕设置：开关 / 字号 / 不透明度 / 显示区域 / 速度 / 屏蔽词 | 已支持 |
| 清屏（临时清 3 秒，不删弹幕条目） | 已支持 |

弹幕取自内容服务端的真实弹幕数据，并叠加你自己发送的弹幕。

## 五、评论与互动

| 功能 | 程度 |
| --- | --- |
| 评论列表分页加载（含真实昵称与头像） | 已支持 |
| 展开查看回复 | 部分支持（只显示首屏回复，翻页未接线） |
| 发表评论 / 回复（保存在本地，发完立刻可见） | 已支持 |
| 点赞（本地记录） | 已支持 |
| 评论草稿按剧集保存 | 已支持 |
| 点头像 / 昵称进入该用户主页（资料、作品） | 已支持 |
| 跨设备同步评论 / 点赞 | 暂未支持 |

## 六、我的

| 功能 | 程度 |
| --- | --- |
| 收藏（含卡片上一键取消） | 已支持 |
| 观看历史（单条删除 / 清空，带确认，上限 2000 条） | 已支持 |
| 观看历史页内检索（按剧名过滤） | 已支持 |
| 预约（已预约 / 即将上线 / 已上线三栏，待上线可就地预约 / 取消） | 已支持 |
| 我的页：历史 / 收藏全量列表 + 已看完 / 未看完筛选 | 已支持 |
| 本地数据保存（位于系统用户数据目录，卸载不删） | 已支持 |
| 导出 / 导入本地数据（换设备迁移，导出为压缩备份；设备身份与窗口尺寸不参与） | 已支持 |
| 清除本地数据（独占一项，需确认） | 已支持 |

## 七、设置

| 功能 | 程度 |
| --- | --- |
| 播放：自动连播、长按倍速、倍速档位 | 已支持 |
| 弹幕：开关、字号、不透明度、显示区域、速度、屏蔽词 | 已支持 |
| 快捷键：总开关 + 逐项改键 | 已支持 |
| 检查更新：检查新版本、下载、安装 | 已支持 |
| 有新版本时启动即提示（顶栏就地下载 / 安装，带真实进度） | 已支持 |
| 本地数据：实时条数概览、导出 / 导入（换设备迁移） | 已支持 |
| 清除本地数据 | 已支持 |
| 画质增强：开关、超分目标（2K / 4K）、质量、锐度、补帧 | 已支持（默认关闭） |
