# 安装说明

## 一、系统要求

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 10 1809（17763）及以上 / Windows 11 |
| 架构 | x64 |
| 内存 | 建议 4 GB 以上 |
| 磁盘 | 安装后约 500 MB，另需缓存空间 |
| 网络 | 需要联网 |

## 二、安装

1. 下载安装包，两个渠道任选其一：

   - **国内加速下载**（推荐，国内网络可直连）：
     [点击下载 红果免费短剧-Setup-0.1.8.exe](https://gh-proxy.com/https://github.com/liangzai-kk/hongguo-short-drama-desktop/releases/download/v0.1.8/hongguo-short-drama-0.1.8.exe)
   - [GitHub 发布页](https://github.com/liangzai-kk/hongguo-short-drama-desktop/releases/latest)：页面打不开或下载过慢时，改用上面的加速下载。

2. 双击运行。
3. 若出现「Windows 已保护你的电脑」蓝色提示，点击 **更多信息** → **仍要运行**。
4. 选择安装目录（默认安装到当前用户目录下，无需管理员权限）。
5. 等待安装完成。安装程序会创建桌面快捷方式与开始菜单项。

> 安装包未购买代码签名证书，因此 Windows SmartScreen 会提示「未知发布者」。
> 这是未签名程序的正常表现，不是安装包损坏。

## 三、首次运行

1. 从桌面快捷方式或开始菜单启动「红果免费短剧」。
2. 首次启动需要数秒初始化本地数据与解码组件。
3. 打开任一剧集即可观看。

## 四、异常处理

| 现象 | 处理 |
| --- | --- |
| SmartScreen 拦截 | 见上文第 3 步 |
| 被杀毒软件隔离 | 将安装目录加入白名单后重装 |
| 启动后白屏 | 关闭程序后重新启动一次 |
| 画面卡顿 | 在设置中降低默认清晰度 |
| 设置页更新下载失败 | 用上文的「国内加速下载」手动下载后覆盖安装 |

## 五、升级

覆盖安装即可，安装目录保持默认时会自动替换旧版本，本地播放记录与收藏保留。

## 六、数据目录

本地数据（播放记录、收藏、设置）保存在系统用户数据目录下：

```
%APPDATA%\红果免费短剧
```

卸载不会删除该目录。若需彻底清理，卸载后手动删除上述目录。

## 七、卸载

- 开始菜单 → 「红果免费短剧」→ 卸载；或
- 控制面板 → 程序和功能 → 选择「红果免费短剧」→ 卸载。

卸载前请先完全退出程序。若提示文件被占用，重启系统后再执行卸载。
