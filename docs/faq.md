# 常见问题

## 本程序开源吗？

**不开源。** 本仓库只发布编译好的可执行文件与文档，不包含源代码，也不提供源码获取渠道。
选择只发布二进制，是为了避免源代码被用于搭建第三方在线服务。

## 为什么杀毒软件报警？

程序未购买代码签名证书，部分杀软会对未签名的打包程序给出启发式告警。
将安装目录加入白名单，或在告警中选择「信任」即可。

## 为什么系统提示「未知发布者」？

同上，未签名程序在 Windows 上的正常表现。

## 程序收费吗？

免费。若你在任何平台付费购买到本程序，说明你遇到了倒卖，请申请退款并举报。
本程序与本仓库不会以任何形式向你收取费用。

## 为什么不能看某些内容？

内容由内容提供方决定，是否可见、是否需要会员由提供方控制。
本程序不对内容做任何存储或再分发。

## 播放失败怎么办？

1. 确认网络可用；
2. 关闭程序后重新打开；
3. 换一部剧集或换一档清晰度重试；
4. 仍失败 → 提交 Issue，附上系统版本与具体剧集。

## 有手机版 / Mac 版 / Linux 版吗？

没有。只有 Windows x64 桌面版。

## 会更新吗？

会按需更新，版本变化记录在 [CHANGELOG.md](../CHANGELOG.md)。

## 我可以把安装包转发给别人吗？

可以，条件是：不收费、不修改、不删除文档、不以官方名义发布。
详见 [LICENSE](../LICENSE)。

## 遇到有人拿这个卖钱怎么办？

不要购买，并在 Issue 中说明情况。倒卖行为与本项目无关，我们也无法为其提供任何保证。

## 如何反馈问题？

在仓库 Issue 中提交，使用对应模板并补充必要信息。
不接受源码索取请求与功能定制请求。
